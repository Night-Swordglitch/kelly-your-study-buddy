# Kelly first release

## Build
- Create the selected Prismatic Glass visual system and an animated Kelly creature with idle, thinking, happy, and concerned expressions.
- Build the public landing and account screens, plus protected dashboard, guided-work chat, memory/profile, settings, and password-reset screens.
- Use the standard chat building blocks for conversation, messages, loading, and the prompt composer.

## Lovable Cloud
- Enable email/password and Google sign-in.
- Add private student profiles, deadlines, memories, preferences, tasks, and conversation records with per-user access rules.
- Connect the screens to live create, edit, delete, and sign-out flows; new accounts receive a starter workspace.

## Verification
- Check desktop and mobile layouts, avatar states, navigation, forms, chat interactions, and all page metadata.
- Resolve build/runtime errors and validate database access rules.

## Scope boundary
- Mood themes and peer networking remain clearly marked future features, with no working logic.
- Reminder preferences and deadline tracking are stored now; external push/email delivery is not included in this release.
